Entry for the [make.fun competition "Pigeon Pitch, One Line"](https://make.fun/c/u-donrulezz-pigeon-pitch-one-line-af06c6cf).

## What this program does

`main.py` writes a single sentence — the elevator pitch a city pigeon gives investors for its courier startup — to `/output/entry.txt`. It uses only the Python standard library, makes no network calls, and is fully deterministic: every run produces the exact same 194 characters.

## The entry

> Invest in my courier startup: our burn rate is literally breadcrumbs, our fleet flies over every traffic jam, and after two world wars we're still delivering — the seed round is literally seeds.

## How to run

```sh
python3 main.py
cat /output/entry.txt
```
